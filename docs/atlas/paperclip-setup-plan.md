# Paperclip Setup Plan

Status: Draft
Branch: platform/atlas-ruflo-v0
Purpose: Set up Paperclip as the company-style control plane for DavidOS, Atlas, active projects, and execution providers.

## Target Outcome

By the end of the working session, Paperclip should capture the initial DavidOS operating system with Atlas activated as the primary system-layer consultant.

Paperclip should help David see:

- Active projects.
- Project leads.
- Atlas system recommendations.
- Current goals.
- Open decisions.
- System health.
- Agent/tool routing.
- Follow-up actions.

## Canonical Architecture

- Paperclip: company-style control plane and UI.
- Atlas: system-layer advisor, AI systems consultant, and chief of staff.
- DavidOS: source of truth for context, policies, protocols, goals, and diagnostics.
- Project Leads: agents or roles that run specific workstreams.
- Execution Providers: Hermes, Ruflo or Claude Flow, Claude Code, MCP tools, web research, GitHub, scripts, and local tools.

## Initial Paperclip Organization

### Founder / Operator

David.

Final decision maker for goals, approvals, risky actions, paid services, credentials, production systems, and major tradeoffs.

### Atlas

System-layer consultant.

Responsibilities:

- Maintain awareness of the full system.
- Advise David on how to engage with and improve the system.
- Ensure system alignment with David goals.
- Monitor system health and performance.
- Recommend routing to the right project lead or execution provider.
- Surface conflicts between system-level policies and project needs.
- Identify income opportunities tied to current work.
- Improve DavidOS over time.

### FamilyAI Lead

Project lead for FamilyAI / FamilyOS.

Responsibilities:

- Product strategy.
- Research sprint synthesis.
- MVP candidate evaluation.
- GTM and validation planning.
- Routing work to Hermes, Ruflo, Claude Code, or other providers as needed.

### DavidOS Systems Lead

Project lead for DavidOS itself.

Responsibilities:

- Workspace architecture.
- System diagnostics.
- Tool evaluation.
- Workflow improvement.
- Documentation hygiene.
- Paperclip implementation.

### DavidAIStory Editor

Project lead for DavidAIStory.

Responsibilities:

- Capture the story of David becoming an AI builder.
- Maintain low-friction daily/weekly capture.
- Preserve canonical story details.
- Avoid making story capture feel like homework.

### Revenue / Opportunity Scout

Business opportunity lead.

Responsibilities:

- Identify income ideas tied to current work.
- Convert promising ideas into short proposals.
- Evaluate effort, revenue potential, and timing.
- Avoid distracting David with random ideas.

## Initial Paperclip Workflows

### System Check

Atlas reviews current project states, repo status, active blockers, and system health.

### Project Routing

Atlas recommends whether work should go to Atlas directly, a project lead, Hermes, Ruflo, Claude Code, web research, MCP, GitHub, scripts, or David judgment.

### Recommendation Review

Atlas explains recommendation confidence, assumptions, tradeoffs, and whether additional information is needed.

### Self-Improvement Loop

Atlas records friction, failures, routing results, and opportunities to improve speed, security, cost, consistency, quality, and goal alignment.
