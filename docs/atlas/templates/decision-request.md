# Decision Request — Issue Description Template

Paste the contents of this file into the description of a new Paperclip issue when the issue is fundamentally a "I need a decision made" issue.

---

## Decision

<One sentence: what is the decision to be made?>

## Options considered

1. <Option A — what it is, what it costs, what it gets us>

3. <Option C — including "do nothing" if relevant>

## Constraints

- Time: <deadline / cadence / urgency>
- Cost: <budget ceiling, if any>
- Reversibility: <reversible | hard-to-reverse | irreversible>
- Dependencies: <other decisions / approvals / installs that must happen first>

## Deadline

<When does this need to be decided by? Why?>

## What would change my mind

<Specific evidence, data, or argument that would shift my preferred option to a different one. If "nothing would change my mind," say so — that's a useful signal that this is a values-driven decision, not an evidence-driven one.>

## Current best guess

<My current leaning, and why. Helps Atlas calibrate research depth.>
