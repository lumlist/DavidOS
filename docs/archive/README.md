# archive/

**Purpose:** superseded material. Read-only audit trail of "what we used to think / used to ship."

**Write permission:** read-only after a file lands here. No edits, no overwrites. If something archived turns out to still be relevant, copy it forward to `wiki/` or `output/` with a fresh authoring step — don't resurrect an archive file.

**Promotion path in:** files arrive here from `output/` (auto, 90 days after issue close), from `wiki/` (only with `[APPROVAL: archive-promotion]`), or from explicit David action.

**Out of scope here:** anything still in active use — keep it in `wiki/` or `output/`.
