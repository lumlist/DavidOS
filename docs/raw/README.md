# raw/

**Purpose:** unpolished inputs — transcripts, screenshots, agent-output dumps, web-extract pastes, scratch notes.

**Write permission:** agents and David may write directly. No approval needed.

**Promotion path:** when content here is durable enough to be reused as reference knowledge, an agent (or David) proposes promotion to `wiki/` via a `[PROMOTION-REQUEST]` comment on a Paperclip issue. David approves with `[APPROVAL: wiki-promotion]`. Atlas then moves the file under `wiki/`, removes it from `raw/`, and posts a `[STATUS]` confirming.

**Curation expectation:** anything in `raw/` older than 14 days that has not been promoted or explicitly archived is curation debt — surfaced in the Daily Operating View "memory freshness" section.

**Out of scope here:** final memos (use `output/`), durable reference (use `wiki/` after promotion), daily notes (use `daily/`), Atlas self-knowledge (use `atlas/`).
